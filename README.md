# XLNC Care

Resident care app for XLNC's Adult Residential Facilities: residents, daily notes, eMAR, out/in, incidents (SIR), quarterly reports (QRT), admission packets, SSI, grocery, staff schedule.

- Hosting: GitHub Pages (static site, no build step).
- Data and login: Supabase (see `SETUP.md`). **No resident data is stored in this repository.**
